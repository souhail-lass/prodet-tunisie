# Images des catégories & sous-catégories

Pour remplacer une image : garde le même nom de fichier
(ex. `linge-textiles.jpg`), aucun changement de code requis.

Format : 1000×750 (4:3), JPEG. Ces fichiers servent de photo d'ambiance en
en-tête des pages sous-catégorie (`famille-hero__media`, affiché en
`object-fit: cover` dans un cadre 4:3).

## Provenance
